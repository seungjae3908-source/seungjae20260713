# 무료 공급원 후속 실측과 독립 OOS 차단 상태

검증일: 2026-10-12 (Asia/Seoul). 기존 무상 공급원 조사와 연구 Draft #1848의 후속 기록이다. 데이터 공급원 가입·약관 수락·결제·키 발급·서버 환경 설정·배포·실제 주문을 수행하지 않았다.

## 실제로 확인한 것

2026-10-12 04:48:50 UTC에 기존 공개 종목목록 수집기로 두 공급원을 다시 GET 조회하고 원본 응답과 정규화 목록의 무결성을 메모리에서 확인했다. SHA는 내용 무결성일 뿐 독립 공급원 인증이나 과거 전체 목록 증명이 아니다.

| --- | --- | --- |
| Upbit 현물 | 현재 전체 응답 868개 중 KRW 294개. 주의 표시 7개도 포함 | 현재 목록이며 거래종료 종목의 역사 목록이 아님 |

같은 작업에서 공개 과거 조회 표본으로 2025-01-02 00:00–02:00 UTC의 BTC 1분봉을 현물·선물 각각 120개 확인했다. 이는 조회 표본이며 전 종목·전 기간 수집이 아니다. 해당 표본의 원본 행은 이번 작업에서 영구 저장하지 않았다. 기존 다른 작업의 2026-10-10 1일 수집 보고서도 이 작업 환경에 실제 원본 파일이 연결된 것으로 계산하지 않는다.

현재 목록을 이용한 1종목/1일 페이지 계획은 두 시장에서 성공했다. 실제 저장 경로 검사에서는 Windows 디렉터리가 기존 POSIX 전용 비공개 저장 조건을 충족하지 못해 `PIT_MINUTE_TASK_ROOT_MUST_BE_PRIVATE`로 차단됐다. 이 검사 이후 분봉 GET은 0건, 추가 영구 보관 분봉은 0개다. 보호 검사를 제거하거나 Windows를 검사 없이 통과시키지 않았다. 확장 수집에는 검증 가능한 비공개 저장소 연결이 먼저 필요하다.

## 발견·수정한 식별자 오류

공개 Bitget 수집기·정규화기·해시 기반 저장소는 한자 원본 심볼을 지원하지만 역사 PIT 심사와 작업 분할기는 ASCII 전용이었다. PIT 분봉 수집 입구는 한자 심볼과 한 글자 base를 거부하면서, 반대로 수집기 한도를 넘는 일부 긴 ASCII 심볼을 허용했다.

시장별 역사 식별자 검사를 PIT 심사·작업 분할·재생·기간 재고 검사·읽기 전용 결과 표시·수익성 심사 연결에서 공유하고, 실제 Bitget USDT 요청 검사는 기존 원본 정규화기와 같은 1–26자 base/총 30자 규칙으로 일치시켰다. 한자 지원은 코인선물에만 적용하며 별칭·번역 심볼·다른 거래소 가격으로 치환하지 않는다. 현재 목록을 역사 PIT로 승인하는 조건, 폐지·중지·재상장 검사, 저장 권한, 누락 분봉, 수익성·Paper 승격 정책은 변경하지 않았다.

신규 순수 회귀 테스트 중 최초 5개는 수정 전 모두 실패하고 수정 후 통과했다. 재생 중단·읽기 전용 결과·canonical 심사 차단 테스트를 더해 신규 7개와 관련 PIT·작업 분할·종목목록·전략 동결 정책 총 57개가 Windows에서 통과했다. 원본 저장 경로의 ASCII/한자/한 글자 심볼 통합 테스트는 기존 Linux CI에서 확인해야 하며 Windows POSIX 저장 차단을 통과로 표시하지 않는다. 테스트의 시세·역사 목록은 명시적 모의 자료이지 실제 취득 증거가 아니다.

## 무료 주식 공급원의 정확한 구분

Alpaca는 무료 실시간 IEX와 무료 과거 SIP를 구분해야 한다. 공식 FAQ는 `end`가 최소 15분 전인 역사 조회에 구독 없이 SIP를 허용한다고 명시한다. Basic 안내에는 2016년부터의 역사 데이터가 표시된다. 무료 계정 인증과 실제 반환 범위, 티커 변경·폐지 이력은 별도로 확인해야 하며 문서만으로 이 계정의 전체 데이터 취득을 인정하지 않는다. [Alpaca FAQ](https://docs.alpaca.markets/us/docs/market-data-faq), [요금제 명세](https://docs.alpaca.markets/us/docs/about-market-data-api)

Massive Basic은 무료 2년 역사 데이터·분봉·참조정보를 제공하는 후보지만 계정 키가 필요하며 10년 전체 PIT 취득 증명이 아니다. [공식 요금제](https://massive.com/pricing?product=stocks)

KRX는 인증키와 개별 API 활용 승인이 필요하다. 공개 서비스 안내 자체가 국내 장기 전체 종목 원본 1분봉 확보를 뜻하지 않는다. 계정 생성이나 약관 승인을 대신하지 않았다. [공식 이용 절차](https://openapi.krx.co.kr/contents/OPP/INFO/OPPINFO003.jsp)

## 독립 OOS 판정

`NOT_RUN_BLOCKED / 미입증`. 실제 평가를 실행하거나 수익률을 산출하지 않았다. 이미 관찰한 BTC 표본을 잘라 독립 OOS라고 부르지 않는다.

필수 미연결 근거는 4시장 과거 전체 상장·폐지·거래가능 상태와 원본 데이터, 검증된 저장소, 앱 신호검색기와 동일한 동결 전략·독립 미접촉 OOS 증거, 당시 수수료·세금·환율·펀딩·유동성·슬리피지·체결 가정이다. 독립 OOS 및 워크포워드 결과가 없으므로 코드 테스트와 CI 성공을 수익성 증명으로 대체하지 않는다.

```text
fourMarketHistoricalDataComplete=false
profitabilityProven=false
OOSPassCount=0
trueMarketWideRecall=null
paperAdmissionAllowed=false
executionAuthority=NONE
realOrders=false
deployed=false
```

기간은 3년에 고정하지 않는다. 요청 기간에 없는 데이터를 짧은 기간으로 조용히 축소하거나, 결측을 기회 0건·수익률 0%로 표시하지 않는다. 무료 계정/승인과 검증된 비공개 저장소가 연결되기 전에는 전체 역사 데이터 취득과 독립 OOS 완료를 선언할 수 없다.
