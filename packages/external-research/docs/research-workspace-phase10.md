# Research Workspace Phase10 — adversarial automatic research chain

Phase10 connects the existing reviewed seams without activating a daemon or granting trading authority.

Flow:

YouTube reviewed source → existing Gemini V7 video observation → Groq adversarial critique → rule completeness → existing canonical video handoff/compiler → existing evidence-backed formula tournament/backtester seam → STOCK/CRYPTO result bucket → adoption review.

Rules:
- Gemini and Groq outputs are research claims only. Agreement between the models is never profitability evidence.
- Groq may challenge or mark a rule missing; it cannot invent a missing entry/exit/stop/sizing/execution rule.
- Incomplete or contradicted rules stop at REVIEW_REQUIRED. The orchestrator never forces a backtest.
- Numeric return, drawdown and cost fields are accepted only from the existing backtester seam identity.
- A losing backtest is a terminal recorded research result. It is not retried until profitable.
- STOCK and CRYPTO completion counts are separate.
- Automatic adoption, scanner/paper/live promotion, orders and execution authority remain disabled.
- Status is read-only from a fixed private file when a future runtime writes it. A missing runtime is unavailable, never “0 completed”.
- No PM2/systemd/cron, server root creation, provider call, deployment, Ready/Merge, Paper, Telegram, private trading API or Replit is performed by this phase.
