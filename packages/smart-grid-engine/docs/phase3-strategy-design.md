## B. Trailing Grid (신규)
- 레버리지: 2x
- 그리드: 20개
- 초기 범위: ±15%
- Trailing 조건:
  - 가격이 상단(+10%) 도달 시 → 그리드 전체 +5% 상향 이동
  - 하단(-10%) 도달 시 → 그리드 전체 -5% 하향 이동
  - **최대 이동**: 원래 범위의 ±20% (누적)
  - **이동 빈도**: 최소 4H 캔들 5개(20시간) 간격
  - **추격 금지**: 현재가가 그리드 상단/하단 5% 이탈 시 이동 중지
- 포지션 일관성:
  - 그리드 이동 시 기존 OPEN 포지션 유지
  - 이동 후 새 그리드에서만 신규 주문 생성
- **엣지 케이스**: 가격이 그리드 범위 완전 이탈 시 → 신규 주문 중지, 기존 포지션만 관리

## C. Neutral Grid (신규)
- 레버리지: 2x
- 그리드: 양방향 (Long 20 + Short 20)
- 범위: ±15% (Long용 lower, Short용 upper)
- 횡보장 감지 조건:
  - ADX < 20 (강한 추세 아님)
  - 볼린저밴드 폭 < 30일 평균
  - → 조건 충족 시에만 신규 진입
- 추세 강해지면 (ADX > 30):
  - 신규 진입 제한
  - 기존 포지션만 관리
- 노출 관리:
  - Long 노출 최대 150 USDT
  - Short 노출 최대 150 USDT
  - 순노출 |Long - Short| ≤ 100 USDT
  - 총 증거금 ≤ 300 USDT
- **롱/숏 손익 분리 기록**
