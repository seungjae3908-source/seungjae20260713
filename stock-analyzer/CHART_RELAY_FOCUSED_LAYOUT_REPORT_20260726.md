# 차트중계 시장별 전체화면 UI 작업 보고

## 적용 구조

- 기술 > 차트중계 > 주식/코인 > 국내주식/해외주식/코인 현물/코인 선물
- 선택 시장은 `focused=1` URL로 차트중계에 전달
- 시장별 제목, 검색창, 실시간 차트중계, 실시간 AI분석만 표시
- 차트중계 화면의 자산 전환 버튼은 시장 선택 진입 시 숨김
- 기존 `분석 화면 보기` 버튼은 선택 자산에 따라 `주식 정보` 또는 `코인 정보`로 변경
- 분석 의견 다음에 상세 전략 표시
- 상세 전략은 매수가/매도가 2열과 1·2·3차, 목표가/손절가 구조
- 서버 가격이 0 또는 잘못된 값이면 최근 캔들 기반 보완 계산 사용
- `거래량 아래 보조지표` 문구 제거 및 차트 내부 선택 글씨 중앙 정렬

## 안전 조건

- 실제 주문 실행 로직은 추가하지 않음
- 자동매매 실행 상태는 기존 차단 상태 유지
