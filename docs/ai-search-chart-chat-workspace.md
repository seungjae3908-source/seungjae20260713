# AI 검색기·AI 차트 분석기·AI 채팅

## 기능 경계

- 기술탭 `AI 검색기`: 국내·미국 주식 조건 검색, 전략·시간봉·임계값, 저장 검색, 점수 근거, 관심종목·상세 이동, AI 차트 분석기 선택 전달
- 기술탭 `AI 차트 분석기`: 기존 실제 캔들 API와 `lightweight-charts`를 재사용한 REST 갱신형 차트, 구조화 분석 상태, 확인·무효 조건, 상태 변경 타임라인
- 정보탭 `AI 채팅`: 공개 금융정보·학습·앱 사용 안내 전용 대화. 주문·계좌·서버·GitHub·배포 작업은 실행하지 않음

1024px 이상 기술탭에서는 기존 검색기와 차트 분석기를 같은 화면의 좌·중앙·우측 영역으로 조합한다. 모바일에서는 검색기를 우선 표시하고 결과의 `AI 차트 분석기에서 보기`를 누르면 선택 상태를 유지한 채 차트 화면으로 전환한다. AI 채팅은 이 기술 화면에 포함하지 않는다.

기존 `/scanner`, 주식 상세, 코인 현물·선물, 백테스트, 모의매매, 거래일지 및 주문 승인 경로는 유지한다. 실제 주문 또는 자동매매 활성화와 연결하지 않는다.

## 선택 전달

`AnalysisSelectionProvider`는 검색 결과에서 선택한 최소 상태를 `sa-analysis-selection-v1`에 저장한다. URL에는 시장·티커·표시명·시간봉 등 복구에 필요한 공개 식별자만 포함한다. 점수 근거 전체는 URL에 넣지 않는다.

전달 항목:

- assetType, market, symbol, ticker, displayName, timeframe
- searchRunId, signalScore, signalRank, confidence, riskLevel
- matchedSignals, reasons, selectedAt

## 검색 점수와 데이터 상태

최종 AI 점수는 실제로 확보된 추세·거래량·유동성·기술·뉴스·재무·시장 요소만 가중 평균하고, 누락 요소의 가중치는 가용 요소에 재분배한다. 확인된 위험 이벤트는 별도 감점한다. 검색 응답에는 각 요소의 값·상태·근거와 실제 시가총액을 포함한다. 데이터가 없으면 수치를 만들지 않고 다음 상태 중 하나를 반환한다.

- `unavailable`
- `insufficient`
- `delayed`
- `stale`

기본 정렬은 AI 점수, 신뢰도, 유동성, 조건 일치 수, 낮은 위험도, 데이터 신선도 순이다. 스프레드 데이터는 현재 주식 검색 공급자 계약에 없으므로 생성하거나 정렬에 사용하지 않는다. 시가총액 조건은 실제 공급 값이 없으면 통과시키지 않는다.

검색기는 KR·US 주식만 활성화한다. 코인 현물·선물 화면과 API는 기존 기능으로 유지하지만 검색 API가 없으므로 AI 검색 시장처럼 표시하지 않는다. 검색 시간봉은 KR에서 5분·15분·1시간·4시간·일봉, US에서 실제 Yahoo 간격이 연결된 5분·15분·1시간·일봉만 노출한다. 저장 검색에는 자산 유형, 시장, 시간봉, 조건, 프리셋, 거래량·거래대금·시총 기준, 최소 AI 점수, 최대 위험 점수, 생성·수정 시각을 보관한다.

관심·알림 버튼은 기존 관심종목 저장소를 갱신하고 해당 종목의 기존 `price_alerts` 기반 지정가 알림 화면으로 이동한다. 별도의 서버 상시 검색조건 알림 워커는 이번 변경에 추가하지 않는다.

## 차트 분석 상태

구조화된 `ChartAnalysis`는 다음 상태를 사용한다.

- forming, candidate, confirmed, weakened, invalidated, expired

최신 캔들의 완료 여부를 공급자가 명시하지 않으면 `forming`으로 유지한다. 완료 플래그가 있는 캔들만 신뢰도와 신호 조건에 따라 `confirmed`, `weakened`, `invalidated`로 전환될 수 있다. 미래 캔들을 참조하거나 나중 데이터에 맞춰 과거 객체를 변경하지 않는다.

현재 차트 데이터는 WebSocket이 아니라 REST 폴링이다. 분·시간봉은 5초, 일 단위 계열은 15초 간격으로 갱신하며 일시정지할 수 있다.

KR 차트는 키움이 제공하는 1·3·5·15·30분, 1·4시간 및 일봉을 사용하고, 4시간은 기존 60분봉 안전 집계를 재사용한다. US 차트는 Yahoo의 1·5·15·30분, 1시간, 일봉만 활성화하며 미지원 3분·4시간 요청은 일봉으로 대체하지 않고 거절한다. 5일·20일 화면은 실제 일봉을 묶어 만든 집계임을 공급자 문자열에 표시한다. 명시적 완료 플래그가 없을 때는 실제 봉 시작 시각과 간격이 지난 경우에만 완료로 파생하며, 5일·20일 집계의 마지막 봉은 임의로 완료 처리하지 않는다.

차트 인스턴스는 REST 갱신마다 재생성하지 않는다. 캔들·이동평균·볼린저·VWAP·거래량·가격선 데이터만 갱신하고 종목·시간봉이 바뀔 때 표시 범위를 재설정한다. 타임라인은 안정적인 분석 ID와 상태 변경만 기록하며 항목을 누르면 해당 분석 캔들 구간으로 이동한다.

## AI 채팅 설정

서버 환경변수 이름:

- `AI_CHAT_PROVIDER=openai-compatible`
- `AI_CHAT_API_KEY`
- `AI_CHAT_MODEL`

새 변수가 없으면 기존 AI 복기용 `TRADING_REVIEW_PROVIDER`, `TRADING_REVIEW_API_KEY`, `TRADING_REVIEW_MODEL`을 호환 설정으로 사용할 수 있다. 값은 프런트 번들, 응답, 로그에 포함하지 않는다. 공급자가 설정되지 않으면 `503 AI_CHAT_NOT_CONFIGURED`을 반환하며 가짜 답변을 만들지 않는다.

서버는 빈 질문, 민감정보, 주문·자동매매·계좌·키·서버·GitHub·배포 실행 요청을 공급자 호출 전에 차단한다. 외부 호출은 20초 제한과 사용자별·IP별 분당 20회 API rate limit을 적용한다.

## 배포 상태

이 변경은 애플리케이션 코드와 테스트만 포함한다. DB migration, Replit 반영, 스테이징 배포, 운영 배포, 실제 주문 활성화는 포함하지 않는다.
