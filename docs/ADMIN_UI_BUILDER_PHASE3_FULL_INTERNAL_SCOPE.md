# 관리자 UI 편집기 3차 전체 내부 편집 범위

## 핵심 목표

관리자가 기존 앱의 모든 편집 대상 화면에서 상위 영역뿐 아니라 내부에 보이는 텍스트, 버튼, 탭, 선택 항목, 카테고리, 안내문, 상태문구를 개별적으로 수정한다.

대상 화면:

- 홈
- 종목
- 종목 상세
- 기술
- 신호검색
- 포트폴리오
- 환경설정
- 하단 메뉴
- 하단 메뉴에서 열리는 모든 단계별 팝업

## 모든 내부 요소에 제공할 기능

- 이름 및 실제 표시 문구 수정
- 표시/숨김
- 삭제
- 삭제한 기존 요소 복원
- 사용자 글씨 추가
- 사용자 버튼 추가
- 사용자 탭 추가
- 사용자 카테고리 추가
- 복제
- 순서 이동
- 너비, 높이, 간격, 정렬, 글씨 크기/굵기, 색상, 투명도, 모서리, 위치, z-index 수정
- 기존 허용 라우트 연결
- 기존 허용 조회 API 연결
- 팝업 제목/내용/위치 연결

## 삭제 규칙

- 기존 앱 요소는 소스에서 제거하지 않고 `visible=false`로 저장한다.
- 게시된 레이아웃 런타임은 `visible=false`인 기존 요소를 실제 화면에서 숨긴다.
- 숨긴 기존 요소는 편집기의 복원 목록에서 다시 추가한다.
- 관리자가 새로 추가한 사용자 요소는 완전 삭제할 수 있다.
- 부모 요소를 숨기거나 삭제할 때 하위 요소도 실제 화면에서 함께 숨긴다.

## 신호검색 전체 내부 편집 대상

다음 항목 하나만이 아니라 화면에 보이는 모든 주요 요소를 개별 항목으로 등록한다.

- 뒤로 버튼
- `신호검색` 제목
- 현재 검색 방식 보조 문구
- 새로고침 버튼
- 단타용·15분봉 탭
- 스윙 탭
- 중장기 탭
- 직접 설정 탭
- `실제 15분봉만 사용 · 거래량/거래대금·단기 추세·지지/저항을 함께 확인` 안내문
- 조건 조합 제목과 선택값
- 결과 정렬 제목과 선택값
- 조건 선택 제목
- 점수 70 이상
- 거래량 확대
- MACD 전환
- 추세 확인
- 위험정보 확인
- 과열 제외
- 위험 제외
- 현재 조건 저장
- 국내주식/해외주식/코인 현물/코인 선물 선택 영역
- 종목 검색창
- 신호 종류 버튼 묶음 및 각 버튼
- 결과 영역 제목
- 로딩, 오류, 빈 결과 문구
- 최대 종목 수 안내
- 하단 투자 책임 문구
- 결과 카드 내부에서 안전하게 수정 가능한 정적 라벨

동적 숫자, 가격, 점수, 종목명 등 데이터 값은 임의 정적 문구로 덮어쓰지 않는다. 정적 라벨만 편집 대상으로 삼는다.

## 하단 메뉴 및 팝업 전체 편집 대상

- 홈/종목/관심/기술/정보/설정 메뉴 버튼
- 메뉴 글씨
- 메뉴 표시/숨김
- 메뉴 연결 경로
- 종목 팝업 닫기 버튼
- 이전 버튼
- 팝업 제목
- 주식/코인 카테고리
- 국내주식/해외주식
- 코인 현물/코인 선물
- 관심, 기술, 정보 팝업의 모든 단계와 내부 카테고리
- 사용자 카테고리 추가 및 허용 라우트 연결

## 구현 원칙

- 각 실제 요소에 안정적인 `data-ui-edit="..."` 식별자를 부여한다.
- `nth-child` 의존을 줄이고 명시적인 식별자를 우선 사용한다.
- UI_COMPONENT_CATALOG에 부모/자식 관계를 등록한다.
- 편집기는 상위 영역을 누르면 내부 편집 화면으로 진입한다.
- 내부 편집 화면에서도 하위 그룹을 다시 열 수 있는 계층형 구조를 사용한다.
- 저장 스키마는 기존 schemaVersion 2와 parentId를 재사용한다.
- DB migration은 추가하지 않는다.
- 기존 게시/초안/롤백 API를 유지한다.
- 런타임은 현재 페이지 레이아웃과 navigation 레이아웃을 함께 불러온다.
- 임의 JavaScript, HTML, CSS 코드, 서버 명령 입력을 허용하지 않는다.
- 실주문 및 자동매매 실행 로직을 수정하지 않는다.

## 검증

- 모든 변경 파일 TypeScript 오류 없음
- 프론트 프로덕션 빌드 성공
- API 프로덕션 빌드 성공
- 기존 UI 편집기 2차 기능 유지
- 삭제 후 게시하면 실제 화면에서 사라짐
- 복원 후 게시하면 다시 나타남
- 새 글씨/버튼/카테고리 추가 후 게시 반영
- 하단 메뉴 연결 변경 반영
- PWA 파일 생성 유지
- APK 다운로드 경로 변경 금지
