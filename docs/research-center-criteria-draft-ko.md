# 연구센터 신규 운영 기준 승인안

상태: 사용자 승인 · 운영 적용 전 검증 필요

승인 내용: 국내·해외 주식과 코인 현물은 1배 매수 전용, 코인 선물은 7배 롱·숏. 나머지는 제안 기준으로 진행.

승인 범위는 공개 시세 수집, 연구, 가상 모의매매뿐입니다. 실제 주문·계좌 자금·거래소 비공개 API는 계속 차단합니다. 아래 수치는 수익 전략 추천이 아니라 기능 검증용 제안입니다.

## 검토할 기준

| 항목 | 제안 |
| --- | --- |
| 시장 | 한국·미국 주식, 코인 현물·선물. 시장별 수집 성공 여부를 따로 표시하고 장 휴장과 장애를 구분 |
| 시세 | 공식 공개 시세의 닫힌 봉만 사용. 원본·수집 시각·출처·코드 버전·파일 지문 저장. 누락·중복·미완성 봉은 검증 표본에서 제외 |
| 첫 기능 검증 전략 | 15분봉, 종가의 지수이동평균 20·60 교차 시 매수, 4개 닫힌 봉 경과 시 청산. 선물 매도는 20·60 하향 교차를 사용. 고정 규칙으로 시작하며 자동 파라미터 탐색·실전 적용은 하지 않음 |
| 분할 | 새 데이터 묶음을 시간순 학습 60%·검증 20%·미사용 검증 20%로 예약. 정확한 봉 식별자와 기간은 결과를 보기 전에 고정. 기존 학습 159건을 재분류하지 않음 |
| 누수 방지 | 경계에서 지표 준비·보유기간이 겹치는 표본을 제외. 미사용 검증 구간과 별도의 최종 보류 구간은 학습·AI 입력에서 제외 |
| 최종 보류 | 미사용 검증 뒤의 별도 미래 구간을 예약하고 잠금. 구간 길이는 실제 수집 일정과 함께 승인 기록에 확정하며, 잠금 해제는 별도 승인 |
| 모의 자본 | 기존 목표 100만원. 기존 계정 잔고를 덮어쓰지 않음. 새 가상 계정만 100만원 초기화 |
| 모의 위험 한도 | 주식·현물은 1배 매수만, 코인 선물은 7배 롱·숏. 진입당 증거금 최대 25%, 동시 포지션 1개, 진입 가격 대비 불리한 방향 1%에서 손절, 손절 기준 예상 손실은 자본 0.5% 이내. 수량은 자본·손실 한도를 모두 충족하도록 제한. 더 엄격한 기존 안전 제한은 유지 |
| 비용 | 수수료·세금·스프레드·슬리피지·펀딩·지연·유동성 영향·부분체결 8개를 각각 출처와 함께 저장. 미확인을 0으로 대체하지 않음. 비적용 0도 증빙 필요 |
| 비용과 모의거래 | 예상 비용으로 기능을 시험하더라도 실측과 구분. 필요한 비용 또는 수량 규칙이 없으면 해당 후보 진입을 차단. 비용 8항목 미충족 시 순손익·수익성 통과 처리 금지 |
| 폐쇄루프 | 같은 후보의 신호→진입→보유→청산→비용→정산→거래일지 연결을 검증. 재시작·중복 실행 후에도 거래와 잔고가 중복 생성되지 않아야 함 |
| AI와 영상 | 확인된 Gemini·Groq 무료 경로만 사용. 유료 대체 경로 차단, 주기당 AI 최대 3회·영상 최대 3개. 영상 원문은 사용 권한이 있는 입력만 분석 |
| 회원 | 승인된 회원은 공유 연구 결과만 조회. 전략 실행·AI 호출·운영 설정은 관리자, 개인 거래일지는 본인 권한으로만 조회 |
| 수익성·승격 | 기능 동작과 수익성 입증을 분리. 통계·미사용 검증·최종 보류·실제 비용이 갖춰지기 전 수익성 통과 및 전략 승격 차단. 최소 표본·성과 임계치는 별도 검토 전 미정 |

60·20·20 분할, 전략 파라미터와 모의 위험 한도는 사용자가 이번에 승인한 연구 기준이며 수익성을 보장하는 기준이 아닙니다. 시간순 검증과 훈련·평가 사이 간격은 미래 정보 누수를 줄이는 장치이고, 많은 전략 중 성과가 좋은 전략을 고르는 과정의 과적합 위험은 별도로 다뤄야 합니다. [시간순 검증 문서](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.TimeSeriesSplit.html), [백테스트 과적합 연구](https://www.davidhbailey.com/dhbpapers/backtest-prob.pdf)

## 승인 후에도 필요한 실제 입력

운영용 전략 파일, 시장별 대상 종목과 기간, 사전에 고정한 분할 영수증, 실제 비용 증빙, 수량·환율 규칙, 모형·지표 식별자, 영구 저장소를 연결해야 합니다. 테스트 자료를 운영 근거로 복사하지 않습니다. 기준 승인만으로 검증 표본·비용 증거·수익성 증거가 생성되지는 않습니다.

배포 완료 기준은 테스트·QA·스테이징 통과, 소스와 서버 버전 일치, 실제 AI 호출 응답, 같은 후보의 모의정산·일지 저장 확인입니다. 24시간 지속성과 수익성은 이후 실제 관측으로 확인합니다.
